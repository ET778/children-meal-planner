# 多吃快跑微信小程序

这是由原始单页 HTML 改写成的微信小程序项目。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹。
4. AppID 可先使用测试号，后续上线时再换成正式小程序 AppID。

## 已迁移功能

- 月龄/年龄阶段切换
- 喂养建议和注意事项
- 单日/一周餐单规划
- 早餐、午餐、晚餐、汤品选择
- 自定义菜品添加
- 删除备选菜品与恢复默认菜品
- 宝宝备注本地保存
- 餐单复制到剪贴板

## 说明

原 HTML 的 `html2canvas` 截图导出不能直接在微信小程序中使用，所以当前先改为复制文字餐单。后续如需图片分享海报，可以继续用小程序 `canvas` 补一个海报导出页。
